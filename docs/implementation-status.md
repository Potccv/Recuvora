# 实现状态与自动验证边界

本表只记录通用宿主当前可运行能力、自动检查入口和未覆盖边界。具体受监控产品、对象类别、实例、业务字段、故障样本、活动部署、提供方私有事实和跨项目真实环境验收由对应集成项目维护，不进入宿主状态记录。

## 自动验证入口

- 根 `Cargo.toml` 登记宿主测试目标；[测试目录](../tests/README.md)说明每组测试的职责和限制。
- `scripts/check.ps1` 运行格式、Clippy 和宿主测试；`scripts/check-ui.ps1` 检查共享前端与 Desktop 编译边界。
- 监控自动测试覆盖规则阈值、重复或乱序样本、空批次、时效与覆盖、动态发现、检查点、故障归并、确认、重启和关闭排空。
- 外部协议测试使用受限夹具进程，覆盖握手、能力、命名空间、schema、调用许可、工作区归属、工具回调、取消和未知结果。
- 审批及动作测试使用隔离目标和项目外临时目录，覆盖精确绑定、过期、撤销、一次消费、文件身份、并发变化和 Unknown 核验。
- UI 测试使用模拟 HTTP 与最小 DOM，覆盖认证、权限、revision、分页、草稿与焦点保留、轮询取消、POST 不重试和不可信文本展示。

## 记录边界

- 自动测试只证明相应宿主契约和实现路径，不替代目标专属采集、业务判断、外部动作或恢复验证。
- 协议夹具、合成文件、模拟 HTTP、静态构建和编译检查不是活动部署或提供方集成验证。
- 具体集成项目负责自身业务 schema、观测字段、故障分类、供应商进程和真实环境验证；宿主只核验通用接入及可信公共边界。
- 活动配置、凭据、运行数据、实例身份、环境地址和部署核验不得提交到宿主项目。
