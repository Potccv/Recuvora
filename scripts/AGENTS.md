# 开发脚本规范

继承 [项目规范](../AGENTS.md)。脚本入口见 [README](README.md)。

- 构建与测试数据路径必须位于源码根之外，不能静默回退到项目内。
- `build-ui.ps1` 的 `Web`、`Desktop`、`All` 目标必须始终从 `src/interfaces/ui/public/` 读取同一组资产；不得为某一载体生成或维护另一套源码。
- Web 输出、资产清单、Cargo target 和桌面可执行文件全部位于调用方指定的项目外构建根。脚本不得在源码树创建 `dist`、`node_modules`、缓存或打包产物。
- Tauri 构建辅助的工作目录和 `gen/schemas` 同样必须在项目外；`build.rs` 暂存所需构建输入，不维护第二份 UI。新增原生权限或平台配置时同步扩展暂存输入与原始文件变更跟踪。
- 共享静态资产构建保持零第三方前端依赖；如未来引入包管理器或生成步骤，必须先说明锁文件、离线/可复现行为、供应链和项目外缓存路径，不得静默下载或修改全局环境。
- 检查失败保留非零退出码，不将未执行的检查报告为通过。
- `check-ui.ps1` 的静态构建、UI 不变量测试与 Clippy 结果只证明相应检查，不得报告为浏览器、Tauri 运行时、业务 API 或端到端操作验证。
- 清理只能处理本次创建并记录的资源，禁止递归清空调用者传入的目录。
- 不修改全局工具链、PATH 或用户凭据。
- CI 可以在隔离 runner 安装项目固定版本工具链；Action 使用核验过的官方提交，默认测试不得依赖外部提供方凭据，远端运行状态与本地检查分别报告。
