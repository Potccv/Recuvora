# 用户交互模块开发规范

继承 [源码模块规范](../AGENTS.md)。职责与状态见 [README.md](README.md)，接口遵循 [插件规范](../../docs/plugins.md)。

## 本域约束

- `ui/public/` 是 Web 与 Desktop 的唯一前端资产源；页面结构、样式、路由和演示数据只能在这里维护。Desktop 外壳不得复制或分叉界面，Web 构建不得改写源码资产。
- 官方 UI 基础壳包含通用管理和标准业务页面，Harness 会话、修复详情、日志查询与模拟实验室均属于官方范围，不拆为必须单独安装的 UI 插件；这些页面已通过统一 HTTP 客户端消费可信服务。
- 后端能力来自内置模块、宿主侧插件或外部节点，不决定标准页面的交付归属。官方页面通过统一的版本化服务契约访问能力清单、权威视图和操作入口；提供方缺失时显示未配置或不可用，不将其混同于缺少 UI 插件。
- 插件界面扩展只补充官方尚未覆盖的专属视图和自定义展示；不得将已有标准页面迁出官方交付。Web 与 Desktop 保持可选，宿主不得因没有 UI 或 UI 关闭而停止后台运行。
- UI 默认真实模式，未连接时不填充演示数据；只有显式演示模式使用 fixture，并持续标识和禁用提交。真实模式必须展示连接、权限与数据时间，只有服务允许的操作才可提交，前端不能推导授权。
- Browser 与 Tauri 只允许有载体相关的薄适配差异，不得产生不同的功能范围、权限语义或权威状态。Cargo feature 和壳层检测不能替代运行时能力探测。
- 通过服务依赖获取权威视图和提交入口，不导入具体提供方内部实现；配置选择可信内置或远程提供方。
- 内置 CLI 与轻量入口随宿主发布，复杂运行时及独立扩展隔离；远程调用显式区分断连、提交未知与业务拒绝。
- 事件、连接和资源绑定实例，注销或卸载清理不能撤销已经持久记录的人工决定，也不能自动批准待定请求。

- 界面呈现权威业务服务生成的任务和授权视图，不在前端或插件内复制权威状态机与审批规则。
- 每个决定绑定权威业务服务验证的用户身份、请求标识与版本；插件本地“已登录”或“用户同意”字段不是凭据。
- 授权前清楚展示目标、允许操作、有效范围和处理模式；不以笼统确认替代权威业务服务要求的具体决定。
- 对过期、已撤销或已处理请求重新读取权威业务服务状态，不默认同意，也不让旧页面覆盖新决定。
- 区分请求已发送、权威业务服务已接受与实际执行结果；断线视图展示数据时间和连接状态。
- 修复任务授权不能隐含插件安装、更新或启用配置修改；管理入口单独满足相应权威业务服务权限校验。
- 日志、补丁、OCR 和模型内容使用安全展示方式，不能因渲染不可信内容触发脚本或操作。
- 目标侧页面只使用“观测记录/记录流”中立语义，不展示或推断具体采集器配置、文件名、轮换规则、产品字段、实例或活动部署；错误分类完全服从服务返回的显式配置。
- 静态演示数据也按不可信内容安全渲染；禁止用动态 HTML 注入展示模型输出、文件差异、路径或外部错误。
- Harness CLI 只消费 registry 契约，不导入具体适配器；配置加载与提供方装配归 boot。路径参数保留操作系统编码，文本文件按大小上限读取并校验 UTF-8。
- 文本调用要求显式选择可见性与原生项目策略；项目 ID 必须由所选 Harness 探测确认，探测失败不能作为空列表或自动切换实例。
- 发现与提交共用命令截止时间；取消传递给每个请求并保留提供方的未知结果。不得用界面层 future 丢弃把已提交操作误报为确定取消，或自动重试会话与项目创建。
- JSON 结果区分提供方原生项目与独立客户端归组；未经客户端观察保持 unverified。错误保留所有已知关联信息与 auto_retry=false，所有外部字符串交给 JSON 编码器转义。
- 缓存、订阅与证据读取遵循身份和任务范围，退出或权限变化后取消相应访问。
- 实现后验证身份绑定、并发决定、重放与断线恢复，授权事实以 [架构设计](../../docs/architecture.md) 的权威业务服务记录为准。
- `repair` 人工决定仅由可信本机入口提交，模型工具不暴露此通道；解析层不制造批准，Unknown 和原有操作关联完整展示。
- Tauri 壳不注册业务 command；Web/Desktop 共同使用带 Bearer 认证的 `/api/v1` 服务。令牌只留内存，审批绑定 revision，提交回执丢失时保留 Unknown，不能把 CLI 解析器直接暴露给页面或自动重试副作用。
