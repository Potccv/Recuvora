# 共享用户界面开发规范

继承 [用户交互模块规范](../AGENTS.md) 和 [源码模块规范](../../AGENTS.md)。职责与当前状态见 [README.md](README.md)。

- Web 与 Desktop 必须复用 `public/` 下同一套页面、样式、路由和数据模型；承载环境差异只进入薄壳适配，不能复制业务界面或授权流程。
- 官方 UI 基础壳同时包含通用管理和标准业务页面；Harness 会话、修复详情、日志查询、模拟实验室不得拆成需要另行安装的 UI 插件。标准页面通过共同 HTTP 契约访问真实服务。
- 标准页面通过统一的版本化服务契约消费能力清单、权威视图与操作入口，不因后端是内置模块、宿主侧插件或外部节点而改变官方页面归属。缺少提供方时显示未配置或不可用，不能用演示数据冒充实际结果。
- 插件界面扩展仅补充官方未覆盖的专属视图和自定义展示，不替代官方标准页面交付。UI 为可选客户端，关闭界面不应终止宿主后台任务或节点连接。
- 保持零第三方前端依赖。不得在本目录新增 package manifest、依赖缓存、构建输出或平台专属源码；确需引入工具链时先更新项目级设计和检查流程。
- 所有外部、模型、文件、日志、JSON 和错误文本必须用 `textContent`、`createTextNode` 或等价安全文本 API 渲染。禁止使用 `innerHTML`、`outerHTML`、`insertAdjacentHTML`、`document.write`、`eval` 或动态脚本拼接。
- 目标侧读取统一呈现为观测记录与记录流；不得显示或推断具体采集器配置、文件名、文件轮换、产品字段、实例或活动部署。`stream_label` 与 `available_streams` 只作为提供方定义的中立标签，错误记录只按服务端显式分类呈现。
- 只有可信后端返回的能力与权威记录可以驱动业务状态。前端不得复制审批状态机、签发许可、推断业务成功或通过本地缓存恢复决定。
- 默认真实模式，未连接时不填充演示数据；演示模式只能显式进入且所有副作用入口禁用。真实操作同时检查服务权限、依赖可用性及当前记录的 allowedActions；可信服务仍核验身份与 revision。
- `Unknown` 独立于失败和取消展示；不得提供通用重试。核验文案必须说明只读取当前状态、不重复动作。`business_verified=false` 必须显示为“业务恢复未验证”。
- `configured` 不等于在线、已认证或已探测；Harness 的配置、认证和运行状态分别展示。隐藏会话不应描述为离线或不发送数据。
- 模拟任务与真实 repair 记录在导航、颜色和文案上保持隔离。模拟结果不得汇总成真实修复成功率。
- 规划能力使用统一“规划中/未实现”视图，不制造实时指标、空列表或健康状态。独立插件框架能力不得描述为已有外部插件加载器。
- 离线、陈旧数据、请求提交中、权威接受、结果未知和终态分别表达。提交决定绑定请求 ID 与 revision，并在冲突后重新读取权威记录；禁止自动重试副作用 POST。
- API 客户端集中在 `public/api.js`，令牌只留内存；不跟随重定向，不携带 Cookie，不缓存业务响应。服务地址只接受 HTTPS 或回环 HTTP，不能增加任意明文远程来源。
- 不在浏览器持久存储策略、审批、目标文件、凭据、模型回复或运行记录。持久化只允许无敏感内容的界面偏好。
- 保持键盘可操作、可见焦点、语义化标题和表格、状态文字与颜色双重编码，并支持 `prefers-reduced-motion` 和窄屏布局。
- 监控与故障属于官方页面。健康状态、样本新鲜度、采集完整性和故障处理状态分别展示；采样调度运行中不能解释为目标健康。故障确认只记录已知悉，不解除条件、不授权或启动修复；resolved 只表示异常条件解除，不代表修复或业务恢复验证。
- 故障全文按需读取，确认收到依赖完整详情的 `allowed_actions`、权限和准确 revision。陈旧详情禁止确认，409 后读取完整新版本，未知回执只核验、不重复 POST；备注、证据和样本始终使用安全文本渲染。
