# 知识与经验能力

本目录规划经验存储、检索、适用条件匹配和证据索引插件，用于复用经过验证的修复经验。

**当前状态：仅有目录与设计文档，尚无知识后端或可运行插件。** 简单可信 Rust 后端可内置并随宿主发布；复杂原生依赖、独立安装和第三方实现默认进程外。

## 职责与组织

- 本域组织知识契约、存储与检索提供方及相关消费者，按实际后端组织子模块；配置按服务依赖选择实现。
- 保存知识条目的来源、版本、适用环境、方案、验证证据和失效条件，区分候选、有效、停用及失败尝试。
- 权威任务记录、授权事实和恢复日志由 [自愈业务服务](../recovery/README.md) 维护，不由本域后端承载唯一副本。
- 内置实现的新增代码须更新宿主；独立扩展经元数据校验、实例握手及能力注册接入。索引任务、订阅与连接绑定实例，清理不撤销已提交的知识写入。
- 知识命中提供候选方案，不代表当前目标适用，更不产生执行权限。

## 输入、输出与权限

- 查询输入包含故障特征、平台、目标版本及筛选条件；写入输入包含来源事件、稳定条目标识和验证结果。
- 输出包含候选、匹配依据、适用限制、知识版本和证据引用，避免只返回无法追溯的结论。
- 申请必要的后端网络、数据目录或证据访问权限；不能直接改写权威任务状态与授权策略。
- 私有索引、缓存和运行数据与源码分离，数据迁移及证据保留规则由对应模块说明。

## 失败与验证计划

- 区分无匹配、后端不可达、索引未就绪和证据缺失，不能将检索失败当作不存在已知方案的可靠结论。
- 后端故障不阻止权威任务记录恢复；依赖知识的流程暂停相关步骤，经验交付由自愈业务服务保留受控待办，重试写入去重且不重放已完成修复。
- 实现后验证重复提交、版本冲突、陈旧索引、后端中断、迁移与恢复，以及失效方案停止参与匹配。
- 当前尚未选定数据库或检索方案，不承诺知识命中的准确率及跨版本泛化能力。
