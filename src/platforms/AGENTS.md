# 平台交互开发规范

继承[源码模块规范](../AGENTS.md)；修改平台契约、代理或接入要求时同时阅读对应子目录的 AGENTS.md。
本域设计与当前状态见 [README.md](README.md)。

- 本域维护宿主侧桌面契约、消费逻辑、代理与外部节点接入约束，不提供节点程序。专属新业务契约及消费者可由第三方宿主侧插件增加，遵循 [插件设计](../../docs/plugins.md)。
- 下述本机 API、权限、会话、进程与资源要求由独立节点实现和验证；本目录记录接入条件，宿主核验能力与结果，不收纳节点后端源码。
- 桌面输入、采集及原生依赖在受监督进程内运行，按会话与故障范围划分；独立扩展校验元数据、启动实例和能力，不要求一服务一进程。
- 外部节点自行选择实现语言；必要原生桥接需封装 FFI、线程亲和性、句柄所有权与错误返回，并提交对应接入验证结果。
- 各平台共享服务契约语义，远程代理另行表达延迟、断连与未知结果；不以最低公分母掩盖能力差异或伪造成功结果。
- 能力报告区分未实现、不支持、权限不足、会话不可用、目标失效和操作结果未知。
- 每次副作用调用校验目标身份、有效授权和会话执行令牌；会话变化后暂停输入并重新核验。
- 不根据锁屏、连接方式或平台名称推断全部能力可用或不可用，应验证所选后端。
- 截图及窗口内容作为证据数据处理，不得触发权限提升；采集范围和保存容量应受限。
- 宿主注册与订阅归属消费实例，采集资源及本机子进程归属独立节点；停用先停止派发并处理在途调用，再分别释放所属资源。断线不表示远端回收完成，effect 清理不撤销外部动作，未知副作用交由核验流程处理。
- 独立进程不替代权限隔离；无法落实所需目标或权限边界时拒绝启用相关能力。
- 目标专属适配、字段和资产保留在对应集成项目中，不为运行时修复 AI 开放修改本域插件的权限。
- 本域文档只描述通用平台与会话边界，不记录具体受监控产品、实例、目标流程、故障样本、活动部署或跨项目真实环境验收。
- 平台测试应涵盖目标重建、权限撤销、会话切换、显示变化及资源长期占用；仅对验证过的组合声明支持。
- 新增宿主侧契约或代理模块时补充 README.md 和 AGENTS.md；外部后端的接入说明登记依赖、权限、限制及验证状态，不在本目录增加节点构建或发行目标。
