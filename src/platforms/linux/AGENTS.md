# Linux 平台开发规范

继承[平台规范](../AGENTS.md)及[项目规范](../../../AGENTS.md)。
本目录当前为设计阶段，职责与待验证范围见 [README.md](README.md)。

- 本目录维护宿主侧契约、消费、代理及 Linux 提供方接入要求，不实现或构建节点。下述本机 API、会话、资源和进程约束由独立节点实施并验证；新业务契约及消费者可由第三方宿主侧插件提供。
- X11、Wayland 与各后端的专属实现在独立节点项目内组织，通过统一桌面服务契约报告差异，宿主消费者不导入后端内部实现。
- 不仅依靠环境变量认定会话、连接和权限有效；执行前确认实际后端及目标身份。
- 若采用桌面门户，明确授权与会话生命周期，不能默认用户授权永久有效或跨会话复用。
- 截图与输入分别探测和注册能力；某项失败不得被同一会话其他能力的成功掩盖。
- 目标窗口、显示服务或会话变化后停止使用旧输入上下文，重新核验后才接收相关动作。
- 处理缩放、多显示器及坐标空间转换，输入坐标必须绑定当前画面与目标版本。
- 原生桌面后端运行于受监督的会话进程，配置通过契约选择实现；声明依赖及实例事件，独立扩展先校验元数据与握手。
- 桌面连接、文件描述符、共享内存和采集缓冲区属于实例，在取消与退出路径释放；effect 清理不作为目标动作已回滚的证据。
- 原生桥接需记录线程与资源生命周期要求；异常后返回结构化错误，不自动扩大系统权限。
- 测试区分发行版、桌面环境、显示协议和后端版本；构建成功不作为交互能力验收。
- 运行时修复仅能调整获准目标项目，不得通过会话配置或工具接口改写 Recuvora 插件。
- 外部后端接入说明实际依赖、运行身份、权限边界和验证结果；本目录新增宿主契约或代理模块时补充 README.md 与 AGENTS.md，不引入节点构建目标。
