# Linux 平台插件

本目录规划 Linux 桌面会话、截图、窗口和输入的宿主侧契约、消费与代理，以及外部节点接入约束。具体 Linux 桌面 API 与本机资源生命周期由独立节点实现和验证；专属新业务契约与消费者可由第三方宿主侧插件提供。
当前仅有设计文档，尚无本域契约或代理实现，也未验证任何桌面后端、发行版及桌面环境。

## 能力与边界

- 探测目标所属用户会话、显示环境和可用截图、输入接口。
- 分别报告 X11、Wayland 及具体桌面环境中的能力，不假定两者行为相同。
- 在授权范围内定位目标、采集画面和发送输入，保留可核验的操作结果。
- 提供公共桌面服务，通过事件报告权限、目标及会话变化；进程代理接收调用与取消，并保留未知结果语义。

## 后端与部署设计

以下本机能力、部署和失败处理是外部提供方的接入要求，不表示本目录实现或发布 Linux 节点。

外部提供方自行选择实现语言并组织后端，宿主配置按契约绑定服务；独立节点在匹配用户会话的受监督进程中隔离原生桌面依赖，并自行管理本机进程。
依赖声明、能力注册、事件与采集资源遵循实例生命周期；卸载清理不撤销已产生的输入，独立扩展需元数据与实例握手验证。
截图、输入、窗口定位是否使用原生接口、桌面门户或其他后端，由节点项目选择并提供相应场景验证。
部署需明确交互会话、显示服务连接与运行身份，不能假定后台进程自动取得桌面控制权。
涉及桌面门户的实现还需验证用户授权、会话建立及恢复行为；已启动不代表具备全部能力。
具体后端应列出发行版、系统版本、CPU 架构、桌面环境、显示协议和所需权限。
目标专属流程、业务字段和资产属于对应集成项目，不作为 Recuvora 平台插件的运行时可修改部分。

## 失败与验证

会话切换、窗口重建或显示配置变化时暂停相关输入，重新确认目标与坐标映射。
锁屏、桌面门户会话结束或显示服务断连后的可用性按所选后端验证，各能力分别报告状态。
截图有效但输入不可用时不得继续执行依赖输入的任务；保留原因供自愈调度服务暂停与恢复任务。
输入结果未知时先观察目标状态；禁止因超时、重启或取消回执直接重放动作。
后续验收覆盖授权撤销、显示缩放、多显示器、后端退出、资源释放和重复调用。
独立进程不是完整沙箱，运行身份、文件权限和系统隔离措施须在实际环境验证。
