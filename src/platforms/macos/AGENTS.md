# macOS 平台开发规范

继承[平台规范](../AGENTS.md)及[项目规范](../../../AGENTS.md)。
本目录当前为设计阶段，职责与待验证范围见 [README.md](README.md)。

- 本目录维护宿主侧契约、消费、代理及 macOS 提供方接入要求，不实现或构建节点。下述本机 API、会话、资源和进程约束由独立节点实施并验证；新业务契约及消费者可由第三方宿主侧插件提供。
- 桌面服务契约与提供方分离，按配置选择实现并声明依赖；原生后端在受监督的会话进程运行，独立扩展验证元数据与实例握手。
- 单独检测屏幕采集与辅助功能相关权限，拒绝、未确定和已授权状态不可混为一类。
- 系统授权不替代任务范围校验；输入与采集仍须绑定获准目标、用户会话和执行令牌。
- 权限撤销或会话、窗口身份变化时暂停受影响动作；重新核验成功前不沿用旧能力报告。
- 不自动改写系统权限设置，也不通过备用后端规避用户未授予的权限。
- 注册、事件和原生资源绑定插件实例；必要原生桥接明确对象所有权、线程要求、回调退出及释放，限制不安全代码范围。effect 清理不撤销目标操作。
- 截图与输入统一说明坐标单位，验证缩放、显示器布局和窗口变化后的坐标映射。
- 处理采集流中断、回调延迟和输入结果未知；取消不能直接作为外部动作未发生的证据。
- 权限及会话故障按能力报告，不声称锁屏等状态会统一阻断所有监控或交互后端。
- 明确发布产物身份及更新方式对权限行为的验证要求，不承诺开发态与发行态权限相同。
- 支持声明绑定实测 macOS 版本、CPU 架构、后端和权限组合，并检查长期资源占用。
- 运行时修复 AI 不得改写本域插件及其启用配置；新增宿主契约或代理模块维护自身 README.md 与 AGENTS.md，外部节点接入需登记平台验证结果。
