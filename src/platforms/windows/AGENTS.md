# Windows 平台开发规范

继承[平台规范](../AGENTS.md)及[项目规范](../../../AGENTS.md)。
本目录当前为设计阶段，职责与待验证范围见 [README.md](README.md)。

- 本目录维护宿主侧契约、消费、代理及 Windows 提供方接入要求，不实现或构建节点。下述本机 API、会话、资源和进程约束由独立节点实施并验证；新业务契约及消费者可由第三方宿主侧插件提供。
- 公共桌面契约与具体提供方分离，由配置注入依赖；保持后台服务与用户会话交互进程分离，不假定服务能直接控制获准目标所在桌面。
- 服务到交互插件的连接绑定实际启动实例、用户及会话身份，防止错误路由或冒用会话。
- 每次输入核验当前目标进程、窗口与会话；窗口标识变化或复用时不得沿用旧授权目标映射。
- 会话切换、桌面变化、注销或远程连接变化后暂停相关输入，重新探测能力再恢复。
- 单独验证截图和输入的权限及可用性；不以锁屏等单一状态替代实际后端检查。
- 坐标转换覆盖显示缩放、多显示器和窗口布局变化，输入绑定当前目标及画面上下文。
- 独立扩展需验证元数据和实例握手；能力注册、事件及原生回调绑定实例，不将卸载清理视为目标输入回滚。
- 必要原生调用封装句柄、线程亲和性、回调和取消行为，清理失败须显式报告。
- 输入调用成功仅作为派发结果，业务核验由约定验证流程完成；结果未知不能自动重放。
- 权限不足时报告限制，不自动提升权限、切换到更高权限身份或操作未授权桌面。
- 验证交互进程退出、子进程残留与重启后令牌失效，旧实例未失去操作能力前不转移会话锁。
- 运行时修复 AI 不得改写本域插件或服务配置；新增宿主契约或代理模块需维护自身文档，外部节点接入需登记平台验证矩阵。
