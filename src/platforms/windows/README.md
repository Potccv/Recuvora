# Windows 平台插件

本目录规划 Windows 桌面会话、窗口、截图和输入的宿主侧契约、消费与代理，以及外部节点接入约束。具体 Windows API 与本机资源生命周期由独立节点实现和验证；专属新业务契约与消费者可由第三方宿主侧插件提供。
当前仅有设计文档，尚无本域契约或代理实现，也未验证桌面后端及 Windows 支持版本。

## 能力与边界

- 识别获准目标所在用户会话、目标窗口与当前可用交互能力。
- 在有效授权和会话独占范围内采集目标画面、发送输入并报告结果。
- 检测用户会话、目标进程、窗口身份、显示配置及权限变化。
- 提供公共桌面服务，发布能力与会话事件；进程代理显式报告取消、断连与不确定执行结果。

## 后端与部署设计

以下本机能力、部署和失败处理是外部提供方的接入要求，不表示本目录实现或发布 Windows 节点。

后台服务与用户桌面交互职责分离；桌面插件运行于获准目标所在的用户会话中。
独立节点自行监督其本机交互进程，但服务在线不能作为桌面可操作的依据。
外部提供方自行选择实现语言，宿主配置按服务契约绑定提供方；截图、窗口枚举和输入后端由节点项目选择并按声明的目标场景验证。
能力注册、事件、回调与采集资源绑定实例，清理不撤销已经发生的输入；独立扩展需元数据校验及实例握手。
必要系统 API 桥接需封装句柄、线程和回调生命周期，并验证失败路径。
服务与交互进程间需验证身份、任务、会话和授权，不能仅依赖进程传来的窗口标识。
提供方接入时需列明 Windows 版本、CPU 架构、会话形态及实际权限要求。
目标专属操作规则、业务字段和资产保留在对应集成项目中，平台插件只提供通用能力。

## 失败与验证

用户切换、注销、窗口重建或远程会话变化后暂停相关输入，并重新核验会话与目标。
锁屏、权限变化和不同桌面对截图与输入的影响应分别验证，不作全部能力一律可用或不可用的假设。
目标身份或权限无法确认时停止相关动作；未受影响的监控由对应插件继续报告。
输入接口成功不证明目标业务接受输入；超时或进程退出后的动作结果先核验再决定恢复。
后续验收覆盖缩放、多显示器、窗口句柄复用、会话切换、权限变化及进程树清理。
进程分离不是完整沙箱，需验证运行身份、访问权限和所采用系统约束的实际效果。
