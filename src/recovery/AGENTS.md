# 自愈业务开发规范

继承 [源码模块规范](../AGENTS.md) 与 [项目规范](../../AGENTS.md)；职责见 [README](README.md)，恢复依据见 [架构](../../docs/architecture.md)。

## 权威业务服务

- 任务、授权、持久记录、调度和默认流程通过契约组合；保持框架通用，不把业务状态迁移下沉到框架。
- 可信实现随宿主共同发布；配置选择已有实现不等于动态安装，关键服务替换采用排空与恢复流程。
- 状态迁移集中校验前置条件；外部消息是证据输入，不能直接写入权威状态。
- 持久化失败不确认可靠接收或完成；执行意图、报告结果、业务验证与知识交付分别记录。
- 必需授权或持久服务不可用时暂停相关执行；同一作用域只接受明确的权威提供者。
- 未知方案可以在用户预先委托的明确范围内由指定 Harness 评审；版本不匹配、范围变化或评审不确定时等待人工处理。流程、Harness 与知识输出只提供证据，必须由可信授权服务核验后产生执行许可；人工批准也不得绕过硬策略范围。

## 恢复与验证

- 保留操作已发生但回执丢失的未知状态；先核验目标，再决定能否重试。
- 外部调用不长期持有关键状态锁；明确锁顺序、等待边界和旧执行者失效后的资源交接。
- 存储和状态变更说明迁移中断、兼容及恢复行为；不得以可卸载知识索引代替恢复日志。
- 验证关键持久化点中断、授权撤销、重复派发、服务替换和知识失败，确认任务事实不分叉。
- 运行时修复范围只包含获准目标，不能通过流程插件开放对 Recuvora、插件包或 profile 的修改。

## 当前实现约束

- 原有模拟引擎保持封闭无外部副作用，不添加命令、文件修复、桌面操作或可注入任意执行器入口；正式审批通过独立 `approval` 模块实现，不复用模拟权限。
- 模拟授权只对固定模拟动作生效；真实授权通过独立 `approval` 契约核验，不能复用此布尔字段作为安全边界。
- 单 actor 持有权威任务与日志；持久化完成后才确认状态变化。不得在等待任务完成期间持有全局异步锁。
- 取消与超时必须确认模拟任务退出后才释放执行槽；执行开始后的不确定结果保留 Unknown 并继续阻断同目标，不能自动重放。
- 原型日志有固定格式版本、顺序、容量与单写入者锁。完整记录损坏拒绝启动；未确认末尾残片可截断。
- 测试维护在项目 [tests](../../tests/README.md)，不得在模块内创建测试数据或构建产物。

## 正式审批约束

- `ApprovalStore` 是可信宿主的单写入者同步业务服务，外部 Harness 调用必须在状态变更之外进行；模型输出不能填写宿主身份或构造执行许可。
- 审批绑定完整操作、任务版本、目标、策略快照和过期时间，策略的目标及动作白名单对人工和 AI 审批同样生效。策略范围变化必须新建请求。
- 真实执行前先持久化单次 `Executing` 意图，再交付不可构造的许可；执行端继续核验目标和前置内容。记录失败不得返回许可或确认完成。
- 评审者错误和升级记录 `WaitingHuman`，不伪造模型评审身份。取消和撤销不能复活，执行中不确定保留 `Unknown`；同目标的未知操作阻断新消费。
- 审批日志的任何损坏包括末尾残片均拒绝恢复，不能截断可能的执行意图。恢复只能将执行中记录转为 `Unknown`，已批准记录不自动派发。
- 未知消歧只能在可信调用方独立核验目标状态、确认旧执行者停止后记录完成或失败，不能重新批准原请求。操作人字段仅为审计归属，不代替 OS 身份验证。
- `workflow` 在独立无工具会话中调用审批 Harness；真实动作必须走可信 `actions` 服务，模型不得直接写入目标或存储。人工批准不隐式执行，文件读回不能宣称业务修复完成。

## 真实监控故障约束

- `IncidentStore` 是监控引擎唯一持久故障权威；同一同步提交保存完整来源检查点和按观察顺序排列的信号，不允许先推进游标再落故障。
- 实时提交与回放共用状态规则。每个 monitor 严格序号前进，最新完全相同提交幂等；未知、冲突、容量或存储失败不能报告采集已经可靠接收。
- 区分 target 故障与 coverage 异常；Unknown 不证明目标健康，Clear 只解除已有故障。批内先 Active 后 Clear 也必须保留 episode，后续 Active 新建事件。
- 人工确认必须绑定当前 revision 与可信调用方身份；确认不解除故障，不产生任务授权或执行许可，也不复用模拟状态。
- 时间展示可在墙钟回拨时取已有值，顺序依赖持久序号；不得因 NTP 调整让合法新观察永久无法提交。
- 故障日志完整或末尾残片损坏均拒绝恢复，不能套用模拟日志可截断残片的规则。写盘失败不提交内存或检查点，实例停止接受变更。
- 容量包含已解除历史，达到限制拒绝整个事务，不静默删除或轮转。生命周期关闭先排空采集再释放文件锁；保留的查询句柄不能继续提交或确认。
