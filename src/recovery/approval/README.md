# 审批内部实现

公开类型与操作入口仍在 [approval.rs](../approval.rs)，外部调用路径保持 `recovery::approval`。

- `storage.rs`：单写锁、日志恢复、执行中记录转为 Unknown，以及同步追加后确认。
- `transitions.rs`：实时操作与日志重放共同使用的状态迁移校验，不执行 I/O。
- `paths.rs`：运行目录、普通文件、链接与硬链接检查。

这些文件是同一可信审批服务的私有实现，不能单独装配或替换为第二个权威提供者。执行许可、日志格式和审批语义保持一致；测试仍集中于项目 `tests/`。业务范围见[父层说明](../README.md)。
