# 持久故障内部实现

公开类型、单写入者存储与迁移规则位于 [incidents.rs](../incidents.rs)；本目录的 `paths.rs` 处理外部目录及打开对象身份检查。

每个 monitor 提交完整检查点和一批信号，单条 JSONL 日志同步成功后才改变内存。恢复重用相同状态迁移，拒绝非法顺序、未知格式和完整或半条损坏。Windows 使用拒绝删除共享的目录及文件句柄固定路径，拒绝 reparse point 和硬链接；Unix 检查祖先、设备与 inode 身份及链接数。部署仍依赖可信本机身份与目录权限，不能隔离恶意同账号或同进程代码。

生命周期由监控引擎所有者负责；显式关闭释放文件锁，保留只读历史，禁止再提交或确认。存储不调用来源、不做规则匹配，也不触发审批或修复。业务语义和容量见[自愈业务说明](../README.md#持久故障管理)。
