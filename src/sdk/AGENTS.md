# 插件与节点开发辅助规范

继承 [源码模块规范](../AGENTS.md) 与 [项目规范](../../AGENTS.md)；范围见 [README](README.md)，来源见 [框架](../framework/README.md) 与 [协议](../protocol/README.md)。

## 契约复用

- 本地接口复用框架与领域公开接口，远程接口复用正式协议映射，不建立第二套容器、授权或任务事实。
- SDK 为可选帮助；不得要求外部节点依赖整个 `recuvora` crate、使用 Rust 或安装官方 SDK。具体节点代码、平台依赖和发布流程属于外部独立项目。
- 宿主侧插件可使用现有 JSONL v1 注册命名空间和版本化业务契约/schema，并按许可消费只读能力；SDK 便利封装及通用流程/验证辅助仍属规划。宿主侧指逻辑职责，独立安装插件默认进程外。共同边界遵循 [插件设计](../../docs/plugins.md)。
- schema、节点能力声明及便利封装不得产生执行授权或替代可信权威记录；缺失或不兼容插件只使相关能力不可用，不能自动放宽检查。
- 区分同编译发布的本地模块和独立进程外扩展；本地注册便利函数不得宣传为动态安装机制。
- 便利方法保留目标、作用域、任务、调用和截止时间，不隐式选择不同执行目标。
- 保留结构化错误、取消与未知结果；自动重试只用于已由契约明确可安全重试的操作。
- 资源登记和关闭遵循框架生命周期，清理不等于回滚业务副作用。
- 多语言接口保持字段范围、时间单位和兼容规则一致，不能各自定义协议变体。

## 示例与验证

- 新增接口模块说明运行边界、依赖版本、资源释放和支持范围；支持语言、绑定与分发方式按实际扩展需要及协议验证结果确定。
- 示例基于已实现接口，说明必要权限和可能副作用，不包含真实凭据或自动授权捷径。
- 验证本地依赖清理和远程拒绝、失联、超时、重连路径，不只验证成功注册与序列化。
- 检查输出、队列和等待上限，避免便利封装隐藏无界缓冲或长期阻塞。
- 外部节点仍自行承担本机依赖、监督、目标检查与执行记录义务；示例明确这些边界，不包装成宿主已提供的节点运行时。
- 用共享协议样本验证非官方 SDK 实现与插件契约缺失、冲突、不兼容的行为，不让 SDK 成为事实上的专有接入条件。
- 当前无已发布 SDK 包或语言绑定；已有 wire 协议按协议文档准确描述，不编造 SDK 安装命令或版本兼容承诺。
