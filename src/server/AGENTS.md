# 服务接口开发约定

继承[源码规范](../AGENTS.md)。本模块只将可信服务映射到版本化 HTTP 接口，不复制审批和模拟状态机。

- 只有认证且具有对应权限的请求可读取业务数据或派发操作；身份来自服务端配置。
- 人工决定与执行必须校验当前 revision；凭据不得写入日志或响应。
- 目标侧读取只表达中立观测记录与记录流；不得把具体采集器目录、配置名、文件名、轮换规则、产品字段、实例或活动部署固化到服务文档和示例。错误记录只按配置的 `error_levels`/`error_events` 分类，宿主不得硬编码提供方等级。
- 故障确认直接调用监控/故障权威服务，同步持久化并绑定 revision 与服务端身份；它不创建修复操作或解除故障。监控快照与故障摘要、按需证据分别提供，并检查各自读取权限。
- 接受前持久化操作标识，重复标识拒绝派发；重启后在途操作记 Unknown，不自动重放。
- 网络断开不取消已接受操作；取消有独立入口，必须等待执行者返回其确定或未知结果。
- 监听回环地址；跨机通过 TLS 反向代理或 SSH 转发部署。来源白名单不能代替 Bearer 认证。
- Web 静态资产只能来自官方 UI 的同一份源码；不生成第二套业务页面。
