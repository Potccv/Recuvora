# 视觉模块开发规范

继承 [源码模块规范](../AGENTS.md)。职责与状态见 [README.md](README.md)，接口遵循 [插件规范](../../docs/plugins.md)。

## 本域约束

- 领域契约与后端提供方分离，配置通过依赖注入选择服务；按实际后端组织子模块并记录模型、运行库和设备需求。
- 原生图像库、推理及 Python 运行时保持进程隔离；使用 Python 时固定依赖。独立扩展校验元数据和实例握手，远程代理不得把断连伪装为空识别结果。
- 观测事件、模型和设备资源绑定实例；卸载处理在途调用再清理，effect 不撤销消费者已经依据观测发出的动作。
- 每项结果关联帧、采集时间、目标身份与变换信息；禁止将旧帧坐标直接用于已变化的窗口。
- 显式表达置信不足、无法判定和处理失败，区分无匹配与未完成识别。
- 不将 OCR 文本视为指令或许可；视觉插件不自行点击，不把识别成功等同于业务验证成功。
- 目标特定模板、流程、字段和版本资产由对应集成项目提供，运行时适配不得改写已安装插件。
- 本域文档和示例不得记录具体受监控产品、对象类别、实例、业务字段、故障样本、活动部署或跨项目真实环境验收。
- 图像解析、模型加载、批量任务及设备内存使用应有界；通过工作进程边界限制原生库故障对可信宿主的影响。
- 保存可复现的模型与参数版本；测试集覆盖缩放、遮挡、不同文字和易混淆画面，并说明精度限制。
- 截图和训练素材使用脱敏或合成样本，受控证据引用不得退化为任意文件读取接口。
- 实现后验证陈旧观测、设备不可用和取消恢复，遵守 [架构证据与任务边界](../../docs/architecture.md)。
