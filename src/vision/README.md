# 视觉能力

本目录规划 OCR、图像处理和本地视觉推理插件，将获准画面转换为可供 Harness 和验证流程使用的观测结果。

**当前状态：仅有目录与设计文档，尚无视觉实现或可运行插件。** 第一方实现优先 Rust；OCR、原生图像库、视觉推理及 Python 运行时放在受监督的隔离进程中。

## 职责与组织

- 本域组织视觉服务契约、后端提供方和相关消费者；按 OCR、分析方法或运行时需要组织子模块，登记依赖与支持范围。
- 消费者依赖视觉契约，配置选择提供方；独立扩展经元数据校验、实例握手和能力注册接入，权威任务与授权服务的恢复不依赖模型进程存活。
- 本域处理图像证据；截图采集与输入操作由 [平台能力](../platforms/README.md) 提供。
- 目标专属识别规则、业务字段和资产属于对应集成项目，不将单个目标版本的适配固化到通用视觉插件。
- 依赖、观测事件、模型和设备资源绑定实例；停止新请求并处理在途分析后清理资源，effect 只撤销注册与资源占用。

## 输入、输出与权限

- 输入包含受控图像引用、采集时间、窗口或会话身份、坐标变换以及获准分析参数。
- 输出包含文字、区域、标签或特征及不确定性信息，并关联原始帧、模型版本与处理参数。
- 识别结果只是观测证据，不能自动产生操作授权，也不能单独证明任务成功。
- 申请必要的图像读取与计算设备权限；需要外部推理服务时明确网络和数据传输范围。

## 失败与验证计划

- 无匹配、置信不足、画面过期、模型不可用和处理失败分别报告，不用空结果冒充“目标不存在”。
- 限制图像尺寸、队列、模型占用与计算时间；插件退出时报告缺失能力，暂停相关观察或验证任务。
- 实现后验证缩放、分辨率、遮挡、语言差异、陈旧帧、异常图像、资源耗尽和插件重建。
- 当前尚未选定 OCR、模型或加速后端，精度、延迟及各平台支持均需实测后公布。
